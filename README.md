# Sign Language Converter 🤟

This is a web application designed to help non-verbal people communicate easily. It turns sign language hand gestures into real-time text and speech using a web browser and a computer camera.

> ⚠️ **Status:** This project is still in its development phase. The user interface is ready, and the backend machine learning model is being connected next.

## 🛠️ Built With
- React & TypeScript (Frontend Interface)
- Tailwind CSS (Styling)
